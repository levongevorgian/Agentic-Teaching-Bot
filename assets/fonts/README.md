# PDF Fonts

Place a Unicode TTF/TTC font here if your system does not already provide one.

Recommended filenames:

- `NotoSansArmenian-Regular.ttf`
- `NotoSans-Regular.ttf`
- `DejaVuSans.ttf`
- `Arial Unicode.ttf`

The PDF generator first checks `TEACHING_BOT_PDF_FONT_PATH`, then this directory, then common system font locations. Use a font with Armenian coverage for Armenian output.
